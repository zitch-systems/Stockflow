Communications

Email Tools

Resend confirmations, diagnose delivery issues, and manage user verification.
Email Confirmation Setup Checklist
If users aren't receiving confirmation emails, check these in order:
1. Supabase → Authentication → URL Configuration → add https://stockflow.com.ng/login.html to Redirect URLs
2. Supabase → Authentication → SMTP Settings → configure a custom SMTP (SendGrid, Mailgun, Brevo, etc.) — free tier shared SMTP has a 3 emails/hour limit
3. Supabase → Authentication → Email Settings → verify the "Confirm email" template has the correct site URL
4. Ask users to check spam / promotions folder — Supabase shared SMTP often ends up there
5. Use the manual verification tool below to confirm users who signed up but can't access their email
Manual User Verification
Mark a user as email-confirmed without them needing the email link. Use when email delivery fails.
Resend Confirmation Email
Trigger a new confirmation email for a user who didn't receive theirs. Requires SMTP to be configured.
